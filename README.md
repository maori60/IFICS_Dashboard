# 📊 IFICS Dashboard

Dashboard de gestion pour associations, mairies et établissements.

---

## 🚀 Stack Technique

- **Frontend** : Nuxt 4 (Vue 3, Vite)
- **Backend** : Nitro (API routes)
- **ORM** : Prisma
- **Database** : PostgreSQL (ou autre via Prisma)

---

## ✨ Fonctionnalités

### 👥 Clients
- Liste des clients
- Création de clients
- Types : mairie, établissement, association

### 📁 Projets
- Liste des projets
- Création de projets
- Lien avec clients
- Statuts :
  - Draft
  - Validated
  - In progress
  - Completed
  - Cancelled

---

## 🎨 UI / UX

- Design moderne (light UI)
- Cards propres avec ombres
- Badges dynamiques
- Responsive mobile complet
- Menu sidebar adaptatif
